The Four Distinctions

Needs You have them

Individual requirements for survival, security, belonging.

Beliefs You think them

Mental models and worldviews you hold.

Principles You follow them

Personal operating rules you adhere to.

Values You live them

Inherently relational — requires others.

🌴 Desert Island Test

Values require others to practice. Stranded alone, you cannot practice generosity if there is no one to receive.

Try it: Click values to test. Only relational values (generosity, justice, compassion) pass.
